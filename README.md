# 📝 Todo App

A Todo app built with React, Vite, and JSON Server.

## ✨ Key Features

* **Manage Tasks (CRUD):** Add, inline edit, delete, and mark tasks as done.
* **Search:** Filter tasks by title.

## 🚀 How to Run

**1. Install packages:**
```bash
npm install

**2. Run both Frontend and Backend:**

```bash
npm run dev:all
Vite Dev Server: http://localhost:5173

JSON Server: http://localhost:3001
